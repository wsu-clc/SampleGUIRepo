# SampleGUIRepo
Weber State University's accompanying repository for the Using Git's Graphical User Interface tutorial video
- Accompanying CLC tutorail video: [Using Git's Graphical User Interface]((https://www.youtube.com/@wsucomputerliteracycenter/videos)

In this video we will initialize a repository, add files to commit, look at the status of files staged for a commit, and finally commit a file with a message. All using Git’s graphical user interface.
